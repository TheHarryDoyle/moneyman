# Public Review Snapshot

This repository is a temporary, single-commit portfolio snapshot of MoneyMan prepared for admissions review.

It includes source code, tests, synthetic fixtures, and substantive technical documentation. It intentionally excludes the private Git history, raw market captures, generated datasets, account exports, machine-local configuration, and internal operator handoffs.

The complete research repository remains preserved privately. This public snapshot is not the remote used by any unattended collector.
